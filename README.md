# Risk Analysis & Financial Modeling

## Overview
This project focuses on quantitative risk analysis and financial modeling techniques implemented in Python. 
The notebook combines portfolio risk estimation, stochastic modeling, hedging methodologies, and derivative pricing applications.

## Components
- Portfolio return and volatility analysis
- Value-at-Risk (VaR) estimation
- Correlation and beta analysis
- Hedging strategies with futures and options
- Delta-neutral portfolio construction
- Monte Carlo simulation techniques
- Financial risk evaluation

## Methodology
The analysis applies statistical and quantitative finance methods to evaluate portfolio exposure and implement systematic hedging strategies under different market conditions.

## Tools & Libraries
- Python
- NumPy
- Pandas
- Matplotlib

## Key Findings
The implementation of quantitative hedging and risk management techniques reduced portfolio exposure and improved risk control compared to unhedged positions.
